eml2web

This is a small publishing pipeline: an email becomes a page here.

email -> parser -> HTML -> GitHub -> GitHub Pages

There is no CMS, no editor, no dashboard. Writing an email and sending it is the act of publishing. The email's plain-text body is escaped and dropped into a bare <pre> block, next to its own headers (From, Subject, Date, ...). The only formatting applied is *bold*, _italic_, and turning URLs into links - nothing else is reformatted or reinterpreted.

Adding #word anywhere in an email's subject tags the post; the Index groups every post by tag.

Inspired by old plain-text email archives like yarchive.net.

See the Index for all posts, or About for who's writing them.
